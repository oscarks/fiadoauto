# App Frentista

Aplicativo mobile para frentistas (Flutter).

## Requisitos

- Flutter SDK
- Dart SDK

## Setup

```bash
flutter create --org com.fiadoauto --project-name app_frentista .
flutter pub get
```

## Descrição

- Autorização online de abastecimento
- Captura de evidências (foto hodômetro, geolocalização)
- Sincronização com backend
